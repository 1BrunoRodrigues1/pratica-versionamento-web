# Projeto Web: Portfólio Acadêmico

Projeto desenvolvido para praticar versionamento de código com Git, GitHub Desktop, Visual Studio Code e apoio de Inteligência Artificial.

## Objetivo

Criar uma página web simples e documentar sua evolução por meio de commits pequenos, organizados e descritivos, utilizando um repositório Git local e sua publicação no GitHub.

## Tecnologias utilizadas

- HTML5 — estrutura e conteúdo da página.
- CSS3 — estilização e apresentação visual.
- Git — controle de versão do código.
- GitHub Desktop — inspeção de alterações e criação de commits.
- GitHub — hospedagem do repositório remoto.
- Visual Studio Code — edição dos arquivos.
- Live Server — visualização local da página durante o desenvolvimento.
- Inteligência Artificial — apoio na elaboração e revisão das mensagens de commit.

## Estrutura do projeto

```text
pratica_versionamento_web/
├── index.html
├── styles.css
├── README.md
├── SUGESTAO_IA.md
└── HISTORICO_COMMITS.md
```

O diretório `.git` armazena os dados do histórico local do Git.

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html`.
3. Inicie o Live Server, caso a extensão esteja instalada, ou abra o arquivo diretamente no navegador.
4. Edite os arquivos HTML ou CSS conforme necessário e confira o resultado no navegador.

## Versionamento de código

As alterações devem ser organizadas em commits que representem mudanças relacionadas. Antes de criar um commit, confira os arquivos modificados e revise as diferenças apresentadas pelo GitHub Desktop.

Exemplos de prefixos para mensagens de commit:

- `feat:` para adicionar funcionalidades.
- `fix:` para corrigir problemas.
- `docs:` para atualizar documentação.
- `style:` para alterações de formatação visual.

## Uso de Inteligência Artificial

A IA pode ser utilizada como apoio para sugerir mensagens de commit a partir das alterações realizadas. Toda sugestão deve ser revisada para garantir que descreva fielmente o conteúdo alterado.

## Histórico de desenvolvimento

O arquivo `HISTORICO_COMMITS.md` apresenta uma tabela de referência para documentar os commits do projeto. O histórico deve corresponder às alterações efetivamente registradas no Git.

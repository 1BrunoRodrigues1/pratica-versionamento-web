01 — APRESENTAÇÃO

Sobre o projeto

Este projeto tem como objetivo aplicar conceitos básicos de desenvolvimento web e controle de versão por meio da criação de uma página utilizando HTML e CSS.

A atividade também explora o uso do Git para registrar alterações, do GitHub para hospedar o repositório remoto e de ferramentas de inteligência artificial para apoiar tarefas como a elaboração de mensagens de commit.

O desenvolvimento é organizado em etapas, permitindo observar a evolução dos arquivos e compreender a importância de manter um histórico claro das mudanças.

04 — CONTROLE DE VERSÃO

Por que utilizar Git?

O Git é um sistema de controle de versão distribuído. Ele permite registrar mudanças realizadas nos arquivos, consultar o histórico do desenvolvimento e comparar versões.

Cada commit representa um registro de alterações selecionadas. Para que o histórico seja útil, as mensagens devem ser objetivas e explicar o propósito da mudança.

05 — APOIO À PROGRAMAÇÃO

Inteligência artificial no desenvolvimento

Ferramentas de inteligência artificial generativa podem ajudar a revisar trechos de código, explicar conceitos técnicos e sugerir mensagens de commit a partir de uma descrição das alterações.

Essas sugestões devem ser avaliadas pelo desenvolvedor. É importante verificar se a mensagem representa fielmente as mudanças realizadas, evitando descrições genéricas ou informações que não correspondam ao código.

EXEMPLO DE SOLICITAÇÃO À IA

“Analise a descrição das alterações realizadas neste projeto e sugira uma mensagem de commit curta, clara e coerente com o conteúdo modificado. Não invente alterações que não foram informadas.”

06 — ACOMPANHAMENTO

Resultados e próximos passos

A página permite demonstrar a aplicação de HTML e CSS em um projeto web simples. O uso conjunto do editor, do navegador e do repositório remoto oferece um contexto prático para estudar organização de arquivos e controle de versão.

Como próximos passos, podem ser documentados os commits efetivamente realizados, as diferenças entre versões, as sugestões produzidas com auxílio de IA e as evidências obtidas durante a execução da atividade.
